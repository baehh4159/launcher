# M0 실기기 실험지 (PRD §17)

APK: https://github.com/baehh4159/launcher/releases/download/latest-debug/app-debug.apk
설정은 책상 오른쪽 위 톱니(⚙). 결과는 표에 적어 다음 대화에 붙여 주세요.

## 준비
1. 설치 후 책상의 '기본 홈으로 설정' 카드 → 이 앱 선택.
2. 삼성 설정 › 디스플레이 › 내비게이션 바 › **스와이프 제스처**, 뒤로가기 감도는 평소 쓰는 값.

## 실험
| # | 과제 | 방법 | 기록 |
|---|---|---|---|
| 1 | 분리형 정확도 | 설정 › 실험 › 분리형. 오른손 엄지로 오른쪽 가장자리 안쪽을 훑어 "빈 고정 자리 2" → "문구" → "전체" → "앱" … 무작위로 20회 열기 | 맞게 열린 수 / 20, 체감 속도 |
| 2 | 비교군 정확도 | 설정 › 실험 › 오른쪽 표시. 같은 과제 20회 | 맞게 열린 수 / 20 |
| 3 | 머물러 열기 | 분리형에서 엄지를 원하는 높이에 대고 움직이지 않고 기다렸다가 떼기 20회 | 원하는 칸이 열린 수, 너무 빠르다/느리다 |
| 4 | 바로 적기 위 3동작 | 맨 아래 '바로 적기' 오른쪽 끝에서 ① 짧게 탭 ② 머물렀다 떼기 ③ 위로 훑기, 각 20회 | ①은 바로 적기 안내, ②③은 서류철 — 잘못 잡힌 수 |
| 5 | 뒤로가기 충돌 | 훑는 중 엄지가 가장자리 쪽으로 쏠려도 뒤로가기가 실행되는지 20회 | 오작동 수 |
| 6 | 경계 떨림 | 두 칸 경계에 엄지를 대고 3초 가볍게 떨기 | 진동 횟수 (목표 0–1) |
| 7 | 취소 | 훑다가 엄지를 화면 가운데로 빼고 떼기 10회 | 열림 0, 확정 진동 0인지 |
| 8 | 진동 | 설정 › 촉각 세 가지 바꿔 보기 | 칸 이동이 '틱', 열 때 '딱'으로 구별되는지 |
| 9 | 창 | 앱 칸 → 앱 서랍, ㄱㄴㄷ 색인 훑기, 하단 검색, 앱 실행. 창 빈 곳 오른쪽으로 밀기·뒤로·홈 버튼으로 닫기 | 답답함·오닫힘 |

## 조정 가능한 값 (말씀만 주시면 바꿉니다)
칸 간격 56dp · 책등 폭 40dp · 훑기 영역 폭 64dp · 가장자리 여유 8dp · 머묾 300ms(길게 누르기×0.75) ·
경계 여유 15% · 취소 거리 64dp · 창 여백 10dp · 밀어 닫기 120dp/600dp/s
